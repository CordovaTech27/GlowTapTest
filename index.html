Customer App Wireframes

End Customer mobile app · Customer-Functional-Spec.md §4.1 · Phone frame ~390×844 · Auth required (no guest mode)

§4.1 Authentication

  • Splash — app launch: logo, name, loading bar → Sign in after ~2.7 s (tap to skip) · hold on splash
  • Sign in / Welcome — Password (email + password) or OTP (email or mobile, then the code) → Home. Google: first account → Your details, second account → Home
  • Sign in — bad credentials
  • Sign in — account disabled
  • Sign in — session expired
  • Forgot password: Email or mobile → 6-digit code (expires in 2 min, resend after 30 s · expired · type 000000 for wrong code) → New + confirm password → Done
  • Create account (mobile): Mobile number → Phone OTP → Your details (name, email + inline Verify → 6-digit code, password + confirm — 8+ chars, 1 uppercase, 1 number, 1 symbol, DOB, gender, Terms ✓, marketing ✓; type 000000 for wrong code) → Home
  • Create account (Google): Your details (email auto-verified, add mobile) → Phone OTP → Home
  • Legal (demo): Terms & Conditions · Privacy Policy — opened from the sign-up tick and Profile → More options

§4.2 Home — Nearby

  • Home — location, wallet, favourites, cart icon (badge = count), categories, promo, salon cards, floating tabs · Favorites
  • Select location — search, use current location, map pin, selected address + Confirm → Home header
  • Search — full page from Home's search bar: recent / popular / categories, results with Sort by + filters · example: “Hair”
  • Rating colours — 5 colour bands (0–1 … 4–5) used on every rating

§4.6 My Bookings

  • Bookings — Upcoming / Past / All; Past: tap salon row (›) for details; completed unrated shows Book again + Rate & review on one row (no Details button)
  • Booking detail — timeline, payment, cancel / reschedule
  • Reschedule — new date & time only (no payment) → Appointment rescheduled → booking after reschedule
  • Cancel a Confirmed booking: cancel sheet → Cancellation initiated → booking · Cancellation initiated → salon confirms → booking · Cancelled (confirmed by salon)
  • Cancel a Booked booking (instant): cancel sheet → Cancellation confirmed → cancelled booking
  • Rate & review — only after a completed booking (My bookings / booking detail / rating alert); overall + stylist rating, salon aspects, written review, photos → shown on the salon’s Reviews tab with a “Verified visit” badge

§4.9 Notifications

  • Alerts — All / Bookings; booking alerts clear once opened, offers stay (reset demo alerts)

§4.7 Profile & account

  • Profile — edit (header button) · Account: password · billing address (list + edit) · add address (line 1, line 2, city, PIN, state) · my reviews · More options (deactivate with OTP · delete; 000000 = wrong code)
  • Favorites — saved salons + liked stylists
  • Edit profile — opens in view mode · edit mode (DOB, gender, marketing on by default) · change avatar (6 options)
  • Change password
  • Subscription — GlowTap Plus plans
  • My wallet — balance, Add money (sheet open), transactions
  • Add money (Home wallet pill and My wallet, same sheet) — amount → UPI or card → UPI ID (verify → approve in app → money added) · card details (bank OTP → payment failed)

§4.8 Help & support

  • Help hub — FAQ · Contact · My tickets
  • FAQ
  • Contact support — customer care number, email, WhatsApp
  • New ticket (from My tickets → New) · same reason is allowed; the booking that already has that reason is blurred: Payment / refund
  • My tickets — service, last reply, who it's waiting on · Ticket conversation: reply needed · waiting for GlowTap Care · resolved (reopen)

§4.3 Salon detail & §4.5 Booking

  • Salon detail — back + cart icon (badge), hours, tabs: Overview · Services (Add → sticky Continue to cart) · Stylists · Ratings & reviews (Rate only with a completed visit · already reviewed)
  • Cart — services + appointment; footer Review & pay › opens booking Review with the saved slot (not Pay now). No time yet → Pick time & pay. If the held slot is taken while you wait: slot taken banner + Reschedule
  • Cart (Zomato-style): selecting services auto-saves; Home card shows View cart · Review & pay. One salon only; another salon replaces the cart
  • Book flow — services → date + slots (2+ services: service tabs) → specialist → review → pay. From a stylist (Book with Priya / favourites / Stylists tab): Service → time → Review only — specialist step skipped
  • Book from a service — skips the service step, starts at specialist
  • Booking confirmation · Payment failed
